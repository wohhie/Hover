# Bookstore Website Repo

This directory contains a standalone starter website for a bookstore called **PageTurner Books**.

## Run locally

Because this is a static website, you can open `index.html` directly in your browser or run a simple local server:

```bash
cd bookstore-repo
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — page structure
- `styles.css` — styling
- `script.js` — dynamic book cards and newsletter behavior
